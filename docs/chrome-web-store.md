# Chrome Web Store 发布资料

## 标题

PDF下载助手 - PDF Downloader

## 简短描述

自动捕获网页中的 PDF 文档，支持搜索、阅读和一键下载课程课件、论文、报告和内部资料。

## 详细描述

PDF下载助手是一款面向学习、办公和资料整理场景的浏览器扩展。它可以自动发现网页中的 PDF 文档，并在当前网页登录上下文中读取文档，支持通过浏览器阅读器打开或保存到本地。

适合教育平台课件、讲义、教材、企业内部资料、学术论文、研究报告、白皮书等 PDF 文件整理。扩展提供文件搜索、今日记录筛选、登录态记录筛选、浏览器阅读、单个下载和批量下载功能。

扩展不会上传你的浏览记录或文件内容。PDF 请求记录仅保存在本机浏览器的本地存储中，你可以随时在扩展弹窗里清空。

## 搜索关键词

PDF下载, PDF downloader, PDF download helper, 下载PDF, 课件下载, 论文下载, 报告下载, 文档下载, PDF阅读, PDF捕获, browser extension

## 权限用途

- `webRequest`：识别网页中的 PDF 文档请求。
- `storage`：在本地保存最近捕获的 PDF 请求记录。
- `tabs` / `activeTab`：把下载或阅读指令发送到当前网页，使用当前网页登录上下文读取 PDF。
- `<all_urls>`：支持在不同网站识别 PDF 请求。扩展只在本机处理请求记录，不上传数据。

## 隐私说明

本扩展只在本地浏览器中处理 PDF 请求记录，不采集、不上传、不出售用户数据，也不会把文件内容发送到第三方服务器。

## 测试步骤

1. 构建扩展：`bash package.sh`。
2. 打开 `chrome://extensions/`。
3. 删除旧版本扩展。
4. 开启开发者模式，加载新的 `dist` 目录。
5. 打开含 PDF 预览或 PDF 链接的网页。
6. 点击扩展图标，确认能看到 PDF 记录。
7. 分别测试复制链接、打开阅读、单个下载、批量下载、清空列表。
